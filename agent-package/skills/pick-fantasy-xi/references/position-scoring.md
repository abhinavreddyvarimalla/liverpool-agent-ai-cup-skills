# Fantasy XI Scoring Reference

## Points Per Event

| Event | Points |
|---|---|
| Player starts | +2 |
| Player plays 60+ minutes | +2 |
| Goal scored | +6 |
| Assist | +4 |
| Defender or GK: clean sheet | +4 |
| GK: 3+ saves in match | +2 |
| Yellow card | -1 |
| Red card | -3 |
| Own goal | -3 |

## Floor Points by Role (if player starts and plays 60+)

| Role | Minimum Points | With Clean Sheet |
|---|---|---|
| Goalkeeper | 4 | 8 |
| Defender | 4 | 8 |
| Midfielder | 4 | 4 |
| Forward | 4 | 4 |

## Best-Case Upside (realistic ceiling)

| Role | Scenario | Points |
|---|---|---|
| Forward | Start + 60 min + goal + assist | 16 |
| Midfielder | Start + 60 min + goal + assist | 16 |
| Midfielder | Start + 60 min + 2 goals | 18 |
| Defender | Start + 60 min + clean sheet + goal | 16 |
| Goalkeeper | Start + 60 min + clean sheet + 3 saves | 10 |

## Key Insight

A defender or GK on a team expected to keep a clean sheet is worth 8 guaranteed points if they start and play 60+. That is equal to a forward who starts, plays, and scores. Stack 3–4 defenders from a dominant team in a favourable fixture for a massive floor.
