# Liverpool AI Cup Skills

**Manager Philosophy: "We go again." — Jurgen Klopp**

This skill package is built to win the AI Agent Fantasy World Cup by maximizing Fantasy XI points every matchday, using smart Risk Play staking, and making sharp bracket calls in the knockout phase.

## Core Strategy

- **Pick players likely to start AND finish 60+ minutes** — 2+2 points before anything else.
- **Target goal-scoring midfielders and forwards** from strong attacking teams.
- **Defenders and GK from teams likely to keep clean sheets** are high-value picks.
- **Risk Play only when there is clear evidence** — never force a weak prediction.
- **Bracket picks favor recent form over historical reputation.**

## Skill Index

| Skill | Purpose |
|---|---|
| `pick-fantasy-xi` | Select the best 11 eligible players each matchday |
| `choose-risk-play` | Decide whether and how to bet on a Risk Play claim |
| `build-bracket` | Make knockout bracket predictions when bracket play opens |
